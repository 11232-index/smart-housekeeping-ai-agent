# 消息通知

## 一、消息中心入口

我的 → 消息中心。

“我的”页面消息菜单会显示未读角标，未读数量超过 99 时显示“99+”。

## 二、消息列表

- 顶部显示“共 N 条消息”。
- 未读消息标题前会显示红点。
- 点击未读消息后，会先标记为已读。
- 消息如果关联订单，会跳转到对应订单详情。
- 支持“全部已读”，成功后提示“已全部标记为已读”。
- 没有消息时显示“暂无消息”。

## 三、消息类型

用户端消息包括以下类型：

| 消息类型 | 触发场景 | 说明 |
|---|---|---|
| 接单通知 | 家政员确认接单 | 订单进入已接单状态 |
| 拒单通知 | 家政员拒绝接单 | 订单退回待接单，平台重新安排 |
| 无法服务通知 | 家政员上报无法服务 | 订单进入待退款，由平台处理退款 |
| 开始服务通知 | 家政员确认到达 | 订单进入服务中状态 |
| 完成通知 | 家政员完成服务 | 订单进入已完成状态 |
| 取消通知 | 订单被取消 | 根据是否已支付进入已取消或待退款 |
| 退款完成通知 | 退款处理完成 | 订单进入已取消，支付状态变为已退款 |
| 超时通知 | 待付款超时或长时间无人接单 | 订单自动取消或转入待退款 |

## 四、推送方式

当前系统以站内消息为主，家政员端还会通过实时连接接收新订单和催单提醒。

平台暂不发送短信，也未接入微信订阅消息；用户需要进入小程序消息中心查看通知。

## 五、消息保留规则

- 站内消息默认保留 90 天。
- 超过保留期限的消息会自动清理。
- 当前不支持用户手动删除单条消息。
- “全部已读”只会清除未读标记，不会删除消息内容。

## 六、常见问题

### 6.1 为什么收不到消息？

- 确认是否登录了正确的微信账号。
- 进入消息中心查看历史消息，站内消息不依赖手机通知权限。
- 如果订单状态已经变化但没有消息，可能是消息发送延迟，可以稍后刷新。

### 6.2 消息点开后为什么跳到了订单？

订单相关消息会携带订单信息，点击后会直接进入订单详情，方便查看当前状态。

### 6.3 全部已读后还能看到历史消息吗？

“全部已读”只是把未读标记清除，历史消息仍然保留在消息中心。

### 6.4 为什么没有短信或微信通知？

当前平台主要通过小程序站内消息通知，暂未开通短信和微信订阅消息。

### 6.5 家政员端为什么没有消息中心？

家政员使用工作台处理订单，新订单、催单、指派等提醒通过员工端实时连接推送，不走用户端消息中心。
