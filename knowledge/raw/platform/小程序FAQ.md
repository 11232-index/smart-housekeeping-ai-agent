# 小程序常见问题

## 一、使用与入口

### 1.1 智能家政小程序有哪些功能？

小程序提供以下主要功能：

- 浏览服务分类、服务项目和服务套餐。
- 搜索服务和家政员。
- 把服务加入预约清单并提交预约。
- 选择家政员和可预约时段。
- 在线支付订单。
- 查看历史订单、订单状态和订单详情。
- 管理服务地址。
- 查看和领取优惠券。
- 查看消息通知。
- 使用智能客服咨询问题。

### 1.2 底部导航分别是什么？

底部有四个入口：

- 首页：店铺信息、快捷入口、优惠券、家政推荐、资讯。
- 家政预约：服务预约和家政员预约。
- 预约清单：已选择的服务和套餐。
- 我的：地址、订单、优惠券、消息、客服、退出登录。

### 1.3 怎么找到智能客服？

两个入口：

- 首页快捷入口“智能客服”。
- 我的 → 智能客服。

订单详情页也提供联系客服入口。

### 1.4 怎么查看平台介绍或服务介绍？

- 首页快捷入口 → 关于我们。
- 首页快捷入口 → 服务介绍。
- 首页快捷入口 → 最新动态。

## 二、登录与账号

### 2.1 为什么一直提示授权登录？

小程序使用微信授权登录。需要按页面提示获取微信昵称和头像，并点击“允许”。如果点击“拒绝”，需要重新进入小程序再授权。

### 2.2 登录失败怎么办？

可以尝试：

- 检查网络连接。
- 退出小程序后重新进入。
- 重新完成微信授权。
- 多次失败时联系客服。

### 2.3 怎么退出登录？

我的 → 页面底部 → 退出登录 → 确认。

## 三、预约与下单

### 3.1 怎么预约服务？

家政预约 → 服务预约 → 选择服务分类和服务 → 加入预约清单 → 填写预约信息 → 提交订单 → 支付。

### 3.2 怎么预约指定家政员？

家政预约 → 家政员预约 → 搜索或浏览家政员 → 进入详情 → 马上预约 → 选择可预约时段 → 填写预约信息 → 支付。

### 3.3 为什么不能预约某个时段？

可能原因：

- 该时段已被其他订单占用。
- 家政员当前没有可预约档期。
- 店铺处于休息中状态。
- 页面数据还未刷新。

可以换一个时段、换一位家政员，或稍后再试。

### 3.4 预约日期可以选到什么时候？

- 服务预约：当前页面支持从明天开始，最多可选到第 7 天。
- 家政员预约：当前页面只展示从明天起往后 3 天的可预约时段。
- 具体以页面实际展示为准。

### 3.5 下单需要填写哪些信息？

需要确认服务地址、联系人、联系电话、预约日期、预约时段、服务时长；可选填备注和优惠券。

### 3.6 备注最多能写多少字？

最多 50 字。

### 3.7 可以改期吗？

当前用户端没有独立的在线改期入口。服务开始前 24 小时可以联系客服申请免费改期一次；24 小时内改期可能收取订单金额 20% 的费用；服务开始后不支持改期。

## 四、支付

### 4.1 支持哪些支付方式？

支付页支持微信支付和支付宝支付，具体以页面实际展示为准。

### 4.2 支付超时怎么办？

支付页有 15 分钟倒计时，超时后订单可能自动取消。可以返回订单列表查看订单状态；如果仍需服务，需要重新下单。

### 4.3 已经扣款但订单还是待付款怎么办？

不要重复支付。保留支付凭证，先查看订单状态，再联系客服核实。

### 4.4 重复支付了怎么办？

不要再次付款，保留两次支付记录和订单号，联系客服处理退款。

## 五、订单与售后

### 5.1 在哪里查看订单？

我的 → 历史订单。可以按状态筛选，也可以进入订单详情查看订单号、预约时间、服务地址、金额和退款信息。

### 5.2 订单状态有哪些？

待付款、待接单、已接单、服务中、已完成、待退款、已取消。具体含义见《订单状态说明》。

### 5.3 怎么取消订单？

我的 → 历史订单 → 订单详情 → 取消订单 → 选择取消原因 → 确认取消。

待付款和待接单状态可以取消；已接单、服务中需要联系客服处理。

### 5.4 怎么申请退款？

在订单详情中申请退款或取消，选择原因后提交。已支付订单取消后通常会进入待退款状态，由平台处理退款。

### 5.5 为什么申请退款后订单变成“待退款”？

“待退款”表示订单已进入退款处理流程，平台需要核实并确认退款。退款审核通常 24 小时内完成，退款完成后订单变为“已取消”。

### 5.6 退款多久到账？

审核通过后原路退回，微信或支付宝一般 1-3 个工作日到账，具体以支付渠道为准。

### 5.7 怎么催单？

在订单详情中点击“催单”，平台会提醒家政员或工作人员尽快响应。

### 5.8 怎么再来一单？

已完成的订单在订单详情中支持“再来一单”。服务订单会把可复购的服务重新加入预约清单；家政员订单会跳转到家政员详情重新选择时段。

### 5.9 服务完成后还能退款吗？

服务完成后如发现质量问题，可以在 24 小时内联系客服申请返工；无法返工的，按实际服务情况协商部分退款。

## 六、地址与消息

### 6.1 怎么新增或修改地址？

我的 → 地址管理 → 新增地址或编辑已有地址。需要填写联系人、手机号、所在地区和详细地址。

### 6.2 怎么设置默认地址？

在地址列表中点击“设为默认”；新增地址时也可以直接勾选默认。

### 6.3 消息在哪里看？

我的 → 消息中心。未读消息会有红点，点击后会标记已读；关联订单的消息可以直接跳到订单详情。

### 6.4 消息会保留多久？

站内消息默认保留 90 天。

## 七、服务范围与发票

### 7.1 哪些城市可以服务？

目前覆盖北京和上海部分区域：

- 北京：朝阳区、海淀区、东城区、西城区、丰台区、石景山区。
- 上海：浦东新区、徐汇区、闵行区、静安区。

其他区域是否支持，以预约页或客服查询为准。

### 7.2 可以开发票吗？

支持电子普通发票。订单完成后 7 个工作日内可以联系客服申请开具，发票发送至用户提供的邮箱。

- 人工客服电话：400-888-6688，服务时间 08:00-22:00。
