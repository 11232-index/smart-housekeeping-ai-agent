# 智能家政小程序使用指引

## 一、小程序入口

- 小程序名称：智能家政服务。
- 打开方式：在微信中搜索小程序，或从微信“最近使用的小程序”进入。
- 底部导航共四个：首页、家政预约、预约清单、我的。
- 涉及具体服务价格、家政员档期、订单状态、优惠券余额时，以页面实时查询结果为准。

## 二、首页

首页包含以下模块：

1. 店铺卡片：展示店铺名称、简介、评分、月销量和营业状态。
2. 轮播图：展示平台活动或服务推荐。
3. 快捷入口：最新动态、服务介绍、家政员预约、关于我们、智能客服。
4. 优惠券区：展示普通券和秒杀券，可点击领取或参与秒杀。
5. 家政推荐：展示家政员，点击进入家政员详情。
6. 资讯中心：展示“最新动态”和“服务介绍”的混合内容。

营业状态说明：

- 营业中：可以正常浏览服务并提交预约。
- 休息中：预约相关操作会提示“已经休息了哟，暂时无法预约”。

首页的评分、月销量、店铺地址等为页面展示数据，具体以实际展示为准。

## 三、家政预约

“家政预约”页有两个 tab：服务预约、家政员预约。

### 3.1 服务预约

- 左侧为服务分类，右侧为对应服务或套餐列表。
- 搜索框支持按“服务名称或服务套餐名称”搜索。
- 服务状态为“可预约”时，可以点击“加入预约清单”。
- 服务状态为“休息中”时，不能加入预约清单。
- 如果该服务带有服务需求选项，需要先选择完全部需求，才能加入预约清单。
- 同一个服务不能重复加入；重复添加会提示“已加入相同的服务，请勿重复添加”。

### 3.2 家政员预约

- 顶部搜索框支持按家政员姓名搜索。
- 家政员列表展示头像、姓名、等级、评分、单价和“预约”按钮。
- 点击“预约”进入家政员详情页，再点击“马上预约”选择可预约时段。
- 家政员没有可预约时段时，页面会提示“该家政员暂无可预约时间”，此时不能预约。
- 家政员预约不支持使用优惠券。

## 四、预约清单

- 展示已加入的服务和套餐。
- 支持删除单项、清空整个清单。
- 清单底部展示合计金额。
- 点击“填写预约信息”进入下单页。
- 清单为空时显示“预约清单为空”，需要先回首页或家政预约页添加服务。

## 五、提交预约信息

下单页需要填写或确认以下内容：

1. 服务地址：从地址管理中选择，首次进入会自动带出默认地址。
2. 联系人：必填。
3. 联系电话：必填。
4. 预约日期：按页面可选范围选择。
5. 预约时段：按页面展示的时段选择。
6. 服务时长：按页面展示的时长选择。
7. 优惠券：仅服务预约可使用，每单最多一张。
8. 备注：最多 50 字，可填写特殊要求或注意事项。

提交前会弹出确认框，确认后生成订单并进入支付。

## 六、支付

- 支付页展示订单金额和支付倒计时。
- 支付方式以支付页实际展示为准。
- 支付成功后进入“下单成功”页，可以返回首页或查看订单。
- 未在支付时间内完成支付，订单可能自动取消。
- 如果已经扣款但订单仍显示待付款，不要重复支付，建议先查看订单状态或联系客服核实。

## 七、我的

“我的”页面包含：

- 用户头像和昵称。
- 地址管理。
- 历史订单。
- 我的优惠券。
- 消息中心。
- 智能客服。
- 退出登录。
- 家政员工作台（仅家政员账号使用，普通用户无需关注）。

## 八、智能客服

- 入口：首页快捷入口“智能客服”，或“我的-智能客服”。
- 支持文字提问，可以咨询服务、预约、订单、优惠券、售后等问题。
- 页面提供快捷问题，例如：
  - 日常保洁多少钱？
  - 我的订单到哪一步了？
  - 优惠券怎么用？
  - 阿姨迟到了怎么办？
- 智能客服回答具体订单、金额、档期时，以系统实时查询结果为准。

## 九、常见入口速查

| 想做什么 | 操作入口 |
|---|---|
| 预约日常保洁 | 家政预约 → 服务预约 → 选择服务 → 加入预约清单 |
| 预约指定家政员 | 家政预约 → 家政员预约 → 家政员详情 → 马上预约 |
| 查看订单 | 我的 → 历史订单 |
| 取消订单或申请退款 | 我的 → 历史订单 → 订单详情 |
| 查看优惠券 | 我的 → 我的优惠券 |
| 修改地址 | 我的 → 地址管理 |
| 查看消息 | 我的 → 消息中心 |
| 联系客服 | 首页或我的 → 智能客服 |
| 查看平台介绍 | 首页快捷入口 → 关于我们 |
| 查看服务介绍 | 首页快捷入口 → 服务介绍 |
| 查看最新动态 | 首页快捷入口 → 最新动态 |
